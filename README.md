# AuthDemo

## Description
AuthDemo is an ASP.NET Core Razor Pages application that demonstrates authentication and authorization using cookie authentication. Users can log in with credentials stored in a JSON file, and authenticated users can access a protected Admin page.

## Features
- Login and logout functionality
- Cookie-based authentication
- Password hashing
- User data stored in `data/users.json`
- Protected Admin page using `[Authorize]`

## Default Login
- **Username:** `admin`
- **Password:** `Password123`

## Running the Application
1. Open the project in Visual Studio.
2. Build the solution.
3. Run the application.
4. Navigate to `/Account/Login`.
5. Log in using the default credentials.

## Technologies Used
- C#
- ASP.NET Core Razor Pages
- Cookie Authentication
- JSON file storage
